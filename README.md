# Niti Vahan - eYRC 2026-27

This repository contains the challenge assets and starter code for the eYantra Robotics Competition (eYRC) 2026-27 theme, Niti Vahan (NV).

The project is organized as a set of task folders, each containing a CoppeliaSim scene and/or Python boilerplate for implementing robotics perception and control logic. The goal is to develop an autonomous vehicle that can navigate, detect lane markings/signs/obstacles, and park accurately in simulation.

## Repository layout
